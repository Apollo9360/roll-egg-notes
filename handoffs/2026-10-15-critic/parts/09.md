## 9. Social and co-play (4/10)
Other players can hardly hurt a newcomer on purpose: plots can't be raided, bats are off in the Meadow, and new players get a shield. The problems are accidental. A full server leaves most players with no plot, the shared nests run dry, and there is no invite, no friend payoff a 9-year-old can see, and no show-off moment for the kid.

### The kid's experience
Scenario: a kid arrives from an ad into a server that already has about 8 players, so the plots and nests are shared.

| Time | What happens | Risk |
|---|---|---|
| 0:00 | Spawns on a plot porch, but only if one of the 5 plots is free. `PlotService.assign` (PlotService.lua:212-226) runs once at join and only `warn`s when no plot is free. Plots 6+ spawn at LobbySpawn with no plot. | A kid with no plot can never place an egg, and nothing tells them why |
| 0:10-0:30 | Runs about 11 s to the Meadow nest (world.md). Step 1 says "hold to steal an egg". All 5 nests may already be empty. | Empty nest and a beam to nothing, no message |
| 0:30-2:00 | Grabs an egg. If another player is already being chased, the hen ignores the kid ("second thief gets away clean", GuardService.lua:398-400). Crosses the gold line. Everyone sees the egg grow (CarryController renders it for every carrier). | Positive: friends can bait the hen for each other |
| 3:00-4:00 | Hatches the first pet. Only the kid sees it. Common to Epic hatches are not announced (Rarities.lua:13-16). | No audience, no cheer, no share |
| ~4:00 | If a Roblox friend is in the server: toast "Friend boost: +10% money" (SocialService.lua:69) and a small pill. The kid has about $0 income at this point. | The payoff is invisible, so it doesn't pull the friend in |
| 8:00 and 14:00 of server age | Capture banner (first at 8 min, EventService.lua:46) and Golem banner (first at 14 min, :47). Both are `FireAllClients` toasts (CaptureService.lua:420, BossService.lua:450), and the tutorial is not paused. | Mid-tutorial distraction. The arena ignores the shield (PvPService.lua:325-335). |
| 10:00 after first load | Toast "Your protection ended! ... other players can now bat you" (PvPService.lua:266). | The shield is gone suddenly |
| Day 2 return | `ProtectedUntil` is an absolute `os.time()` stamp (PvPService.lua:191, 194-198). A kid who played 6 min and left is unprotected on return. | First wild-zone trip can end in a lost egg |

### Problems, ranked
1. **Only 5 plots, but the server cap reads 60, with no overflow handling.** [Static] `Players.MaxPlayers` = 60 (execute_luau read, Edit datamodel; the Creator Hub value was not readable). `WorldIndex.PlotCount()` = 5 (world.md). `assign` is only called from `onPlayer` at join (PlotService.lua:299-300), so a plotless player never gets a freed plot. A grep for "MaxPlayers" in all scripts finds nothing. A plotless kid can still grab an egg, but `placeEgg` returns silently when `index` is nil (EggService.lua:784-787), and the tutorial beam to "Plot" resolves to nil (TutorialController.lua:130-132). If the live cap is above 5, the core loop is dead for everyone past the 5th joiner. Servers fill when ads work.
   - Fix: stopgap, set Max Players to 5 in Creator Hub today (confirm the current live value first). Real fix, clone Plot1 to get 8 plots, cap at 8, and add a waiting list so a freed plot goes to the first plotless player. If a player has no plot, show "Server full, joining a roomier server" and use `TeleportService` to move them. Effort XS (stopgap) / M (8 plots) · Impact Very high.

2. **The 5 Meadow nests are first-come and refill only once per ~300 s cycle, but the tutorial needs two nest eggs per kid.** [Computed] `refillNests` runs only on `DayStarted` or events (EggService.lua:1022-1025, 909-917). A delivered egg is destroyed and its nest stays empty (:825-826). Day is 290 s and night is 10 s (world.md). Steps 1 and 12 both need a Meadow egg ("Steal", "Steal2", Tutorial.lua:37 and :53). 5 nests ÷ 2 eggs = 2.5 newbies per cycle, so the 3rd to 10th kid in a busy server may wait up to ~290 s. The beam falls back to the nest centre (TutorialController.lua:121-126) with no text. Grabs are also refused at night (EggService.lua:580). Eggs dropped inside the Meadow do return to the nest, so only delivered eggs drain it.
   - Fix: add a 20 s respawn for any taken Meadow nest egg. The 5 nests then yield 15 eggs per minute instead of 5 per 5 min. If nests are empty, show "Eggs hatch back in M:SS" on the tutorial card. Alternative: a personal starter nest egg that only players with TutorialStep ≤ 12 can grab. Effort S · Impact Very high in populated servers.

3. **There is no invite or referral mechanic anywhere.** [Static] Grep for "Invite" and "PromptGameInvite" over all scripts finds 0 matches. 7-12 year olds mostly arrive alone from ads, so a friend is the only free source of new players, and nothing asks for one. The yardstick says invites should come after real wins, not on a timer.
   - Fix: after the first hatch, show one "Bring a friend" button once. It calls `SocialService:PromptGameInvite`. When the invited friend joins (`Player:GetJoinData().ReferredByPlayerId`, to verify), both get 2x Speed for 10 min or a 15 min Luck token, up to 3 per day. Never show it during the tutorial. Effort S · Impact High.

4. **The friend boost is too small and money-only, so a kid can't see it work in the first 10 min.** [Computed] +10% per friend, capped at +50% (Retention.Social, end of Retention.lua). It multiplies passive and offline money only (Multipliers.lua:53-58). The first pet earns about $24/s (Economy.lua:63-68, starter-egg comment: Owl base $16/s, $24/s with size bonus), so the $100 wheel takes 100/24 = 4.2 s alone and 100/26.4 = 3.8 s with one friend, 0.4 s faster. It counts only Roblox friends in the same server (SocialService.lua:24-39), so a kid with no friends in that server gets nothing. There is no friend name and no "friend joined" moment beyond one toast (:69).
   - Fix: let each friend add +25% wheel Speed gain and +10% egg growth, cap +100% at 4 friends. Name them in the pill ("+25% with Alex"). Show a friend-coloured ring over the friend's head. Effort S · Impact Med-High.

5. **Protection counts wall-clock time, ends without warning, and ends into egg theft.** [Static] `PROTECT_SECONDS = 600` is stamped once at first load (PvPService.lua:63, 194-198). `IsProtected` is `os.time() < ProtectedUntil or Index empty` (:191), and the Index is no longer empty after the first hatch at about minute 3-4 (see Day 2 row above). The only warning arrives after it ends (:265-267). After a bat hit the egg drops, and a dropped (Ground) egg can be picked up by anyone (EggService.lua:577), including the attacker. Step 10 ("watch out for bats and traps", Tutorial.lua:51) plants the fear early but the shield timer ignores it.
   - Fix: store `ProtectionSecondsLeft = 900` and decrement it only while the player is in-game. Keep it until Speed passes the Riverbank gate or Rebirth ≥ 1. Add a "Shield ends in 60 s" toast. Effort S · Impact Med.

6. **Events and server-wide toasts reach kids mid-tutorial, and the Capture arena strips their shield.** [Static] EventController has no `Tutorial.InProgress` check (grep: only Quests, UpgradeHint, Retention and Config use it). Events are scheduled from server start, not player join (EventService.lua:46-47, 232-236). Inside an active arena, `canHit` skips both players' protection (PvPService.lua:325-335). Yardstick: no optional offers during the tutorial.
   - Fix: while `Tutorial.InProgress`, the client hides "Announce" banners that are not about the player (Capture, Golem, Night Run, Rebirth), and the server treats tutorial players as outside the arena. Show the Golem banner after step 11 because it pays money. Effort S · Impact Med.

7. **The co-op boss pays you less the more friends join.** [Computed] HP = 400 × players (BossService.lua:32, 434). Click damage is 2 per 0.25 s = 8 dps per player (:34-36). Reward = income × (60 + 240 × damage share) seconds (:45). Alone: share 1 = 300 s of income in ~50 s. With 10 players: share ≈ 0.1 = 84 s of income each, 3.6x less. Friends add no speed-up (HP grows at the same rate) and no bonus. The 250 floor (:45) is still a real gift to a newbie, since the first wheel costs $100.
   - Fix: add a team bonus, reward × (1 + 0.15 × (fighters − 1)), and raise REWARD_BASE from 60 to 150. Effort XS · Impact Low-Med.

8. **No show-off moments for the kid.** [Static] Only Legendary+, flagged mutations and Huge/Colossal hatches broadcast, as a plain toast (PenService.lua:614-617). Common to Epic gets nothing. The "biggest egg today" statue and boards are top-10 global (Retention.Leaderboards.Top = 10, end of Retention.lua), which a new kid can't reach. No cheer, spectate, emote or photo hook was found.
   - Fix: when a hatch starts, nearby players see a 3 s "X is hatching!" billboard, and the hatcher gets a cheer counter ("Alex cheered!") that pays $20 per cheer. Add a "Friends: biggest egg today" board next to the global one. Effort M · Impact Med.

9. **Characters collide with each other, so crowds can block the nest and the wheels.** [Static] No `CollisionGroup` use in any script (grep: 0). The Meadow `NestArea` trigger is 20×20 studs (world.md) around 5 nests. On a phone, 5+ kids can jam it, and a griefer can wall in a kid.
   - Fix: put all characters in a "Players" collision group that doesn't collide with itself (PhysicsService, 10 lines in PlotService or a new script). Effort XS · Impact Low-Med.

10. **An empty or sparse server feels dead, and the game has no social proof.** [Static] No bots or NPCs found (grep "NPC", "Bot", "fake": only Studio test hooks). That is the honest choice and matches the yardstick. But unused plots just show "Empty Plot" (PlotService.lua:292). A solo kid sees no one.
   - Fix: add a lobby "Recent hatches" feed board with real names from this server, plus a visible "N players here" counter on the Hud. Don't add fake players. Effort S · Impact Low-Med.

### What's good
Plots can't be raided: placed eggs and pets are never PvP targets (PvPService.lua:3-4, EggService.lua:27), which removes the genre's worst newcomer ruiner. New players are untouchable for at least 10 min and while their Index is empty, with a visible "PROTECTED" head tag (PvPService.lua:191, 201-242). Bats are off in the Meadow, lobby and plots (PvPService.lua:143-149). A second thief gets away free (GuardService.lua:398-400). The rare-egg "shared credit" gives bystanders a Luck token (EventService.lua:164-181). The Golem pays every damager at least 250 (BossService.lua:45).

### Top 3 for the summary
1. Fix the 5-plot / 60-player gap: set the cap to 5 now, then build 8 plots with a waiting list (Very high).
2. Make Meadow nest eggs respawn in 20 s, or give tutorial kids a personal starter egg (Very high).
3. Add one post-first-hatch "Bring a friend" invite with a shared reward, and make the friend boost help Speed and growth (High).
