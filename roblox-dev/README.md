# Roblox Development Vault

Verified, practical knowledge for building Roblox games, for people and AI agents. It is also this project's shared memory.

**Open [START HERE](00%20-%20Vault%20Navigation/START%20HERE.md) first.**

| Folder | What's in it |
|---|---|
| `00 - Vault Navigation` | START HERE, maps of content, contributing guide, changelog, research backlog, source index |
| `01 - Context Packs` | What to load before a task: backend, security, UI, Blender, R15 animation, VFX, optimization |
| `02`–`24` | Topic guides, from Luau and networking to discovery and tooling |
| `25 - AI Development Playbooks` | How an AI agent should work on a Roblox project |
| `26 - Decision Guides` | "Which should I use?" answers |
| `27 - Checklists` | Golden rules and checklists for review, release and each discipline |
| `28 - Recipes`, `29 - Code Patterns` | Type-checked Luau to start from |

- Official Roblox docs come first; every note cites sources and has a `last_verified` date.
- Notes link with `[[wikilinks]]`; open the repo root in Obsidian to follow them.
- To add or change a note, follow [CONTRIBUTING](00%20-%20Vault%20Navigation/CONTRIBUTING%20TO%20THE%20ROBLOX%20DEVELOPMENT%20VAULT.md).
