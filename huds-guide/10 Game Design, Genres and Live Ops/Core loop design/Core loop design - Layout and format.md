# Core loop design - Layout and format

Up: [[Core loop design]] · Previous: [[Core loop design - Moment-to-moment feel]]

- Incrementals: a 3D map beats a GUI-only game, which rarely produces good stats.
- Full 3D beats locked-camera 2.5D for social play. Avoid first-person (owner-recommended).
- 2D games: support all devices, have AI make SVG art, never use emojis, and pick a concept not done in 3D. Their audience is real but smaller.
- Shared area versus per-player plots is unsettled. Players standing on plots can block plot buttons.
- Keep maps compact. Long walks between bases kill interaction; put rare spawns in the middle and show icons over bases.
- Invisible but collidable plot hitboxes before unlock frustrate players.
- Put social claim stations (group join, like and leaderboard rewards) physically in the map to cut screen UI.
- For large upgrade trees or areas over 100k studs, consider procedural generation.
