# Finding and validating ideas - Fantasy first

Up: [[Finding and validating ideas]] · Next: [[Finding and validating ideas - Idea sources]]

- Start from the core fantasy and packaging (title, thumbnail, hook), then work backward. Do not start from "I'll make a +1 game" (owner-recommended).
- Decide between a collection fantasy (merging, pets, slimes) and a power fantasy (shredding, crushing, training). Slime audiences expect collection.
- Shooter fantasy is dominating and outsmarting others: skill expression, a high skill ceiling, ranked play.
- Build for one core player type: builders or collectors. Blending works, but pick a broad-audience core.
- Ask what purpose each system serves in the loop. If a base is only for flexing, repackage it (for example, "Build a private island").
- Find a fantasy dominated by one genre and bring another genre to it. Secure the Airport put survival into an airport fantasy that was all roleplay (owner-recommended).
- Hacking into something is a strong core fantasy. Kids know "hacking", not "crypto".
- Weak fantasies fail: "stealing leaves" is weak, and "guess the lucky block" fails because no widely known lucky-block set exists.
- If the core fantasy is weak, no marketing tactic will save the game.
