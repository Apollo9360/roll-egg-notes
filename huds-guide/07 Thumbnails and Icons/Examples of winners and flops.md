# Examples of winners and flops

Up: [[Thumbnails and Icons]] · Previous: [[Estimates and projections (Thumbnails)]]

| Game or concept | Thumbnail | Outcome or lesson |
|---|---|---|
| Steal an Egg | Character running from a monster with an egg | Simple, one focal point; copied by 7+ rivals |
| Grow a Garden, Steal a Brainrot | Core loop shown instantly | Explain the game at a glance |
| Sell Lemons | Green charts and a bacon hair | Signals the business loop instantly |
| Grow a Garden-style for a bouncing-ball game | Character with emotion, giant colorful element, big money text | Better than showing just the object |
| +1 sword game | Before/after: normal avatar vs huge sword, "1 damage" vs "999 damage" | Sells the overpowered fantasy |
| +1 height game | Tiny crying avatar at "1 ft" vs golden giant at "676 ft" | Story with no sentence text |
| Sea-shell game | Bacon hair holding a giant golden clam with a pearl overhead | Must clearly read as a beach |
| Drain the Lake | Just the lake being drained | The thumbnail dictates the core loop |
| Two-player obby | Players colored red and blue, doodle eyes or troll faces | Copy top 2-player obbies |
| Card-pack game | Hand unzipping a pack, card coming out | Instantly reads as opening packs |
| Chest-loot game | Chest spilling loot, hand with key, or x-ray tablet view | Need not be literally in-game |
| Drilling game | Drilling for a kid's idea of treasure | Mining fantasies appeal to kids |
| Bomb game | First-person launch, or explosion with objects scattering | Action-focused formats |
| Cooking brainrot | A large brainrot character in the middle | Flop; at least show it in a pan |
| Merge game | Lucky blocks, stealing, incremental scenes, no merging | Flop; a copied style also failed |
| Soccer game | Top-country flags | Near-zero CTR |
| Gem or rock in water | Abstract object | Fails; show what the player does |
| PvP game | Plain gameplay screenshot | Under 1% CTR |
| Egg game, dark galaxy | 6–10 subjects on a dark background | Lost to a bright blue-sky version |
| Simple, different design | Unlike typical Roblox thumbnails | About 10% CTR |
| Obvious-AI thumbnail | Strong core fantasy | 16% CTR at 1,850 CCU |
| Eye-candy thumbnail | No readable subject | 1.1% CTR |
