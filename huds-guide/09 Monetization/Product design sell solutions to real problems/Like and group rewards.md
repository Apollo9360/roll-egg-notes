# Like and group rewards

Up: [[Product design sell solutions to real problems]] · Previous: [[Product design sell solutions to real problems - Genre examples]]

- There is no API to detect likes. Games pair "like the game" rewards with a trackable group join.
- Verifying likes needs the web API through a proxy such as RoProxy. Most games only check the group join.
- Common formats: "join the group and like the game to receive X", or a SurfaceGui like goal that unlocks an update.
- Games with good like ratios usually just offer free rewards.
