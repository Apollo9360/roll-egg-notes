# Beta Mode

Up: [[Algorithm and Home Recommendations]] · Previous: [[Audience, regions and the 16+ gate]] · Next: [[Algorithm changes and shadowban claims]]

- Beta Mode removes all home-rec impressions; only ad players come in. It is the beta toggle in settings.
- Beta Mode itself does not change your stats, and it stops Roblox ranking the game against its genre.
- Case for it: run ads to fix bugs and balance without the algorithm judging an unfinished game.
- Turn it off and relaunch ads when stats are green. Several report home recs soon after switching off.
- Costs: slower progress and a bigger ad budget.
- A minority call Beta Mode useless, given the 7-day window (disputed).
- Majority view by late September 2026: not worth stressing over; just run live operations.
- It is only worth it with time, money and a committed team.
- Do not enable Beta Mode while waiting for the all-ages unlock.
- Test clickbait thumbnails in Beta Mode first. High CTR from low-quality thumbnails can hurt downstream stats.
