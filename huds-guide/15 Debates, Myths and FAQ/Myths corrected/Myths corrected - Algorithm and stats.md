# Myths corrected - Algorithm and stats

Up: [[Myths corrected]] · Previous: [[Myths corrected - Thumbnails and AI]] · Next: [[Myths corrected - Revenue and CCU]]

| Myth | Reality | Confidence |
|---|---|---|
| Monetization beats engagement | PTR, bounce, play days and playtime come first; official docs treat monetization as secondary. | High |
| Retention isn't a home-rec signal | QPTR, day-1 retention (D1) and play days per user are signals. | Medium |
| Benchmarks don't affect the algorithm | Most believe stats relative to genre benchmarks drive pushes. | Medium |
| The algorithm is luck | It reacts to retention, playtime, PTR and monetization. Luck shapes timing and size. | High |
| Old bad stats will hold a game back | The algorithm uses a rolling 7-day window, so history fades. | High |
| Live ops means fake updates | It means meaningful improvements. | Medium |
| Like ratio drives the algorithm | Likes are an effect, not an input. Games with 40–50% ratios have reached 4k–10k CCU. | High |
| Roblox shadowbans brainrot games | It only punishes bad stats. | High |
| Changing genre hurts the algorithm | It uses more than genre. | Medium |
| Leaving genre blank lets Roblox choose | Benchmarks need a genre; Roblox keeps stats per genre and subgenre. | Low |
| Copying a hit is safe | Only very early, around 200 CCU. Late 1:1 copies perform far worse, and kids recognize them. | High |
| Duplicate experiences tank a game | Not with privated duplicates, in one owner case. | Medium |
| A CCU spike that crashes means the game is bad | Ad and algorithm test spikes are normal. Beat previous stats for the next test. | High |
| Beta mode delays or improves the algorithm | It only hides the game from recommendations until switched off. | High |
| Changing group ownership tanks a game | Reportedly not true. | Low |
| Make the game private to fix bugs | Leave it public and push the fix. | Medium |
| PTR can be 90% | That is a percentile. Real PTR is about 3–5%. | Medium |
| PTR was renamed QPTR | PTR is impressions to plays; QPTR counts plays that stay about 3–5 minutes. | Medium |
| Falling PTR means the game is dying | PTR naturally declines as impressions grow. | Medium |
| High bounce rate is good | It is negative; keep it below benchmark. | High |
| Roblox underreports players | Stats are delayed and inflated early; ~20 daily active users (DAU) against 2,000 visits happens. | Medium |
| 13% D1 is very good | It depends on genre and is unreliable below 100 DAU. | Medium |
| A thumbnail got 1,000 clicks but 1 play | Usually impressions misread as clicks. | Medium |
| Daily or playtime rewards fix D1 or D7 | Not if players dislike the game. The core loop drives D1; deeper progression drives day-7 retention (D7). | High |
| Friends playing can trigger recommendations | Bots don't count, and friends only inflate D1. | Low |
| Other developers are good playtesters | They are not the target demographic. | Medium |
| Visits measure success | Playtime, retention, bounce, QPTR and monetization do. | Medium |
| A high CCU-to-visits ratio guarantees a hit | It is an early signal at best (disputed). | Low |
