# Building, tools and career

Up: [[Myths corrected]] · Previous: [[Myths corrected - Revenue and CCU]]

| Myth | Reality | Confidence |
|---|---|---|
| NumberValue fixes big-number overflow | Only partially: higher range, lower precision. A big-number module is the robust fix. | Medium |
| The Highlight limit is 32 | It is 255 per the docs. | Medium |
| Use Offset so UI scales on mobile | Use Scale. | High |
| Optimized server sizes don't apply to player-versus-player (PvP) games | They still apply. | Low |
| Watching tutorials is enough | Executing teaches far more; launch games (owner-recommended). | High |
| Start with a large first project | Start small and simple. | High |
| Quality means art direction | Quality is good game design. | Medium |
| Product-management skill is enough | Hits come mainly from game design. | Medium |
| Coding skill is essential | Many large games are team-built or AI-coded; the idea and scaling matter more. | Low |
| Successful games had no prior demand | Demand existed and was channeled. | Medium |
| A live ops manager can take a game from 0 to 500 CCU | The idea does that. | Low |
| Roblox is dying | It is highly profitable, and the skills transfer to other user-generated content (UGC) platforms. | Medium |
