# Studio plugins

Up: [[Tools and Resources]] · Previous: [[AI 3D models, animation and textures]] · Next: [[Code libraries and dev tooling]]

| Tool | What it's for | Community verdict | Confidence |
|---|---|---|---|
| [Kekui](https://create.roblox.com/store/asset/91863430524234/Kekui) | Converts UI to Scale with aspect ratio ("ultra scale") | Considered the only plugin needed for AI-built UI. Tutorials and Discord via YouTube. | Medium |
| AutoScale Lite | UI Scale conversion | Free. Use only scale-size and scale-position; usually skip "add constraint". | High |
| [UI Tools](https://devforum.roblox.com/t/ui-tools-the-all-in-one-interface-design-solution/2166473), UI plus, ResizeAlign, [Blob LITE](https://create.roblox.com/store/asset/17430891841/Blob-LITE) | All-in-one UI design, Offset-to-Scale conversion, alignment | Occasionally used alternatives. | Low |
| [RoImport](https://create.roblox.com/store/asset/117468887465055/RoImport-free-Figma-to-roblox-plugin) | Free Figma-to-Studio import | Most-shared importer. See the UI section. | High |
| [Bloxporter](https://devforum.roblox.com/t/bloxporter-beta-paid-fast-figma-roblox-with-custom-configurations/3501193), [FigbloxUI](https://devforum.roblox.com/t/figbloxui-%E2%80%94-figma-to-roblox-ui-in-seconds/4446977), [UI importing masterclass plugin](https://devforum.roblox.com/t/extremely-detailed-roblox-ui-importing-masterclass-w-free-plugin/4619363) | Other Figma-to-Studio importers | Bloxporter is paid. | Medium |
| [Multi-Photobooth](https://create.roblox.com/store/asset/136160532154714/Multi-Photobooth) | Transparent item renders | Export as OBJ to get images on PC. | Low |
| [Model Photobooth](https://create.roblox.com/store/asset/80253277106637/Model-Photobooth) | Model icon renders | [DevForum post](https://devforum.roblox.com/t/model-photobooth-create-asset-icons-with-ease/4550905). Shared in both channels. | High |
| [Photobooth](https://create.roblox.com/store/asset/82716202460157/Photobooth) | Bulk icon renders with strokes and glows | Recommended for icon shots. | High |
| [Resurface](https://devforum.roblox.com/t/resurface-converter-apply-classic-studs-and-more-to-parts-meshes-and-unions/1226536) | Applies stud and checkerboard textures to parts, meshes and unions | Make a custom material with fewer studs per tile. | Medium |
| Archimedes, Reflect, Easy Textures, F3X, Loop Tools | Building; Loop Tools makes circles | Common building set. | Medium |
| Moon Animator with Easy Weld | Animation; welding multi-mesh models | Easy Weld costs about $30. | Medium |
| [VFX Studio](https://create.roblox.com/store/asset/135581141962270/VFX-Studio) | VFX | Free; considered the best VFX plugin. | High |
| Cutscene plugin | Keyframes, camera, depth of field, FoV (field of view), subtitles | Paid and free versions in Toolbox. | Medium |
| [Avatar Catalog plugin](https://create.roblox.com/store/asset/86635366559124/Avatar-Catalog), Catalog Avatar Creator (game) | Avatar outfits for NPCs | Useful. | Medium |
| [Runtime Explorer](https://devforum.roblox.com/t/runtime-explorerv42-drag-drop-debug-for-live-games/2693615) | Explorer-style debugging in live games | Used by a developer with stats. | Medium |
| [Vanilla 3](https://devforum.roblox.com/t/vanilla-3-the-pragmatic-icon-set-for-roblox-studio/935745) | Studio interface icon set | Shared repeatedly. | Medium |
| [RoPrice](https://devforum.roblox.com/t/roprice-%E2%80%94-bulk-create-edit-developer-products-and-game-passes-in-creator-dashboard/4739351) | Bulk create or edit developer products and game passes | Safety unconfirmed. Open Cloud keys are an official alternative. | Low |
| [Completo](https://devforum.roblox.com/t/completo-the-perfect-autocomplete-for-you-and-it%E2%80%99s-free/3874342), [DataDelve](https://devforum.roblox.com/t/datadelve-%E2%80%94-easy-free-datastore-editor/3067950), [Swap](https://devforum.roblox.com/t/swap-powerfully-simple-class-converter/2713629), [PixFix](https://devforum.roblox.com/t/pixfix-faster-pixelfix-alternative/2851072) | Autocomplete, DataStore editor, class converter, image-edge fix | Free; little feedback. | Low |
| TikFinity | Maps TikTok Live gifts to in-game effects | Used early by a breakout game. | Medium |
