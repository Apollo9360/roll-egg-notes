# AI coding and agent tools

Up: [[Tools and Resources]] · Previous: [[Thumbnail and AI image tools]] · Next: [[AI 3D models, animation and textures]]

| Tool | What it's for | Community verdict | Confidence |
|---|---|---|---|
| Claude (Opus, Sonnet) | Scripting, UI, VFX (visual effects), cutscenes, maps | Dominant tool by October 2026. Opus 5.5 widely seen as beating Codex. Sonnet 5.5 is cheaper and good at UI. | High |
| Codex (OpenAI) | Coding agent | Faster, better limits on the $20 plan. Better at UI icons and planning. Claims it is far better for Roblox are disputed. [Usage page](https://chatgpt.com/codex/cloud/settings/analytics). | High |
| Astra (GPT-6), Union Alpha | Roblox-focused models | Good for 3D models, mediocre at Roblox building. Heavy users exhaust usage within about 3 days. | Medium |
| Roblox Assistant | Built-in Studio AI | Under Assistant, three dots. Good for grunt work like searching the tree or anchoring objects. | Medium |
| [Roblox Studio MCP](https://create.roblox.com/docs/studio/mcp) | Connects Claude or Codex to Studio | Owner-recommended over paid plugins like RoPilot. AI Assistant, three dots, MCP, Quick Connect. Exposes 48 tools but only the Edit context. | High |
| [robloxstudio-mcp](https://github.com/Chrrxs/robloxstudio-mcp) | Third-party Studio MCP | Adds client and server runtime plus multiplayer playtesting. Disable Studio's "enable as MCP server" first. | Medium |
| [Dominus 2](https://devforum.roblox.com/t/dominus-2-an-mcp-server-for-roblox-studio-46-tools/4833955), [mcp-roblox-docs](https://github.com/n4tivex/mcp-roblox-docs) | Alternative Studio MCP; docs lookup MCP | Little feedback. | Low |
| Blender MCP | AI modeling and maps | Owner-recommended. Better maps and models than Studio-direct, at higher token cost. | High |
| Figma MCP, Claude in Chrome, Claude Superpowers plugin | Design work, UI concepts, market research | Claude in Chrome can bulk-fill developer product forms. | Medium |
| [RoPilot](https://devforum.roblox.com/t/free-ropilot-available-on-ios-and-android/3791918) | AI Studio assistant | The owner prefers the free Studio MCP. | Medium |
| Gemini | Coding | Rated poor for code. | Medium |
| DeepSeek, Kimi 3, Fable, Sol, Luna Max | Alternative models | Mixed. Luna Max is cheap but fails hard tasks; Sol is decent overall. | Low |
| Obsidian, headroom, rtk | Memory and token saving | Obsidian vault stores skills, references and learnings; headroom and rtk cut tokens. | Medium |
| [Claude effort docs](https://platform.claude.com/docs/en/build-with-claude/effort) | Effort-level setting | Use at least "high"; Opus 5 at medium or high suits planning. | Medium |
