# AI coding and agent tools - Usage tips

Up: [[AI coding and agent tools]] · Previous: [[Skill repos for AI agents]]

- Use Projects plus memory and skills, and start a new chat per task.
- Use plan mode and let Claude ask questions.
- Keep an .md UI style guide and an animations.md for animation conventions.
- Have the AI find skills on GitHub and save them to markdown or an Obsidian vault.
- Templates beat images as references. Supply free asset packs and reference images.
- Generate a reference image before modeling.
- Record a game with lighting you like and have Claude replicate it.
- Describe the end result, not where scripts go. Ask a cheaper model to explain what the agent did.
- Agents script better on the filesystem via Rojo.
- Use Open Cloud API keys so agents can manage game passes, developer products, analytics and data stores.
- As of September 2026, AI cannot do R15 animations and has weak UI taste.
- MCP disconnects: restart Claude, toggle MCP in Studio, or close both via Task Manager and reconnect.
- Codex MCP on Windows: launch cmd.exe with "/c" and the CLI line as arguments.
