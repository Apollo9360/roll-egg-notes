# AI coding and agent tools - Plans and limits

Up: [[AI coding and agent tools]] · Next: [[Skill repos for AI agents]]

- Claude Pro costs $20/month; Max costs $100 (5x) or $200 (20x).
- Most find Pro enough for light use; a minority argue only 20x is worth it.
- A 1-week Pro trial is available through a Max-plan user's referral.
- Claude has a 5-hour window plus a weekly limit. Opus 5.5 can use most of a 5-hour window on VFX.
- `/usage` in Claude Code shows estimated token value, not an extra charge.
- The Codex $100 plan has no 5-hour limit.
- Codex fast mode costs about 2.5x tokens for 1.5x speed.
