# Skill repos for AI agents

Up: [[AI coding and agent tools]] · Previous: [[AI coding and agent tools - Plans and limits]] · Next: [[AI coding and agent tools - Usage tips]]

| Tool | What it's for | Community verdict | Confidence |
|---|---|---|---|
| [roblox-game-skill](https://github.com/brockmartin/roblox-game-skill), [claude-roblox-game-studio](https://github.com/CodePhobiia/claude-roblox-game-studio), [roblox-skills](https://github.com/sentinelcore/roblox-skills), [roblox_libraries](https://github.com/unofficialrobloxtutor/roblox_libraries), [roblox-dev-skill](https://github.com/MSayib/roblox-dev-skill) | Roblox skill sets and library references | Commonly shared starter set. | Medium |
| [roblox-brain](https://github.com/TabooHarmony/roblox-brain) | 29 Roblox skills | Disputed: some recommend it, others call it mostly bloat and doc wrappers. | Low |

- Most experienced developers say skills are unneeded except where AI is weak, such as UI import or modeling.
- Fetching the relevant Roblox docs per task often beats large skill packs.
- A common approach: compile skills with AI, then train on well-built or uncopylocked games.
- Some feed the owner's video transcripts (about 60k words) into an LLM (large language model) as a strategy advisor.
