# Tools & Resources

Up: [[Hud's Guide To Roblox Success]]

The default stack is RoThumbs (about $13–15/month) or Nano Banana 2 via Magnific (about $40/month) for thumbnails, qptr.io for free thumbnail checks, and Claude over the Studio MCP (Model Context Protocol) for code. Kekui or AutoScale Lite handle UI scaling, ProfileStore handles data, and QA Central supplies testers.
