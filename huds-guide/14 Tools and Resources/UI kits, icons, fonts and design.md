# UI kits, icons, fonts and design

Up: [[Tools and Resources]] · Previous: [[Code libraries and dev tooling]] · Next: [[Audio and music]]

| Tool | What it's for | Community verdict | Confidence |
|---|---|---|---|
| Figma | UI design | Free and standard; check the file type at start. Design at 16:9 for PC, then scale with UIScale. | High |
| [RoImport](https://roimport.com/) | Free Figma-to-Roblox importer | [DevForum](https://devforum.roblox.com/t/free-roimport-figma-to-roblox-plugin/4731967), [Figma plugin](https://figma.com/community/plugin/1656014529277439101). Alternatives: FigbloxUI, GPT 1:1 conversion, or frames as images with ScaleType Fit. | High |
| [ui-resources.com](https://ui-resources.com/) | Free sunburst, shine textures, icons, renders, grids | Repeatedly recommended in both channels; also good for sketching thumbnails. | High |
| [gvesster free icon pack](https://gvesster.itch.io/free-icon-pack) | Free icons | Most-shared icon resource. | Medium |
| [gvesster icon pack v4](https://gvesster.itch.io/gvesster-icon-pack) | Paid icons, tiers, stud style | One pack about 9 Robux. | Low |
| [rhosgfx.itch.io](https://rhosgfx.itch.io/) | Simulator icons, item tiers, Vector UI pack | Used by most simulators; free limited versions exist. | Medium |
| [Studs UI Pack](https://builtbybit.com/resources/studs-ui-pack-2.119154/), [brainrot stud UI pack](https://builtbybit.com/resources/clean-stud-brainrot-style-ui-pack.107242/) | Stud-style UI | About $15 for about 8 frames. Most devs use stud packs; a $9.99 kit far outpaced building UI yourself. | Medium |
| [gfxcomet](https://gfxcomet.com/product) | UI and GFX (graphics) assets | Also has a [UI tutorial channel](https://www.youtube.com/@gfxcomet). | Medium |
| [chipng](https://rbxxaxa.github.io/chipng/) | Fixes black outlines on imported PNGs | [DevForum post](https://devforum.roblox.com/t/chipng-fix-edges-around-your-images/2783037). Or try ScreenInsets or PixFix. | Medium |
| [Icon maker](https://flayodev.com/icon-maker/), [rovisuals](https://www.rovisuals.dev/update-icon) | 24-hour hourglass event icon overlays | Devs upload hourglass icons manually; rovisuals is free. | Medium |
| Toolbox 2D assets | Free icons | Search e.g. "rebirth icon" and copy the ID into an ImageLabel. | Medium |
| Unicode glyphs | Robux, Premium and verified symbols in text | [Thread 1](https://devforum.roblox.com/t/unicode-characters-for-roblox-plus-premium-verified-and-robux/2175425), [thread 2](https://devforum.roblox.com/t/release-notes-for-541/1940089/5). | High |
| [Upgraded UI gradients beta](https://devforum.roblox.com/t/studio-beta-upgraded-ui-gradients/4846594) | Richer UIGradient options | Official beta. | Medium |

- Montserrat ExtraBold, Black or Bold is the common UI and thumbnail font. Fredoka One appears in almost every game.
- UI packs are worth buying; AI-made UI and models are often unoptimized.
- A Figma-to-Studio converter using tagged frame classes (button, text-scaled and so on) is in development (low confidence).
