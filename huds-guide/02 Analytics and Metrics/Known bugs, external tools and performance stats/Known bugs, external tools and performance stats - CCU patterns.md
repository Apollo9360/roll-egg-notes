# Known bugs, external tools and performance stats - CCU patterns

Up: [[Known bugs, external tools and performance stats]] · Previous: [[Custom and API analytics]] · Next: [[Known bugs, external tools and performance stats - Performance stats]]

- Judge CCU on week-over-week trends, not hour by hour.
- Drops can be your audience sleeping (for example US or Brazil) or the weekday versus weekend cycle.
- A CCU spike that returns to normal within about 1 min usually comes from updating or restarting servers. Creator Hub does not show it.
- CCU hides acquisition spikes, session length, new versus returning players and spenders versus non-spenders.
- Estimating real new players from ads is noisy. Use visits early, then adjust using retention.
