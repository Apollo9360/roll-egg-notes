# Testing, beta and multiplayer games

Up: [[Ads and Ad Credits]] · Previous: [[Creatives, multiple campaigns and pausing]] · Next: [[Ad players, home recommendations and when to stop]]

- Sanity check: 5 credits for 1 day, extended to 3 days if results aren't terrible.
- Testing phase: 10–16 credits/day for 3–5 days until D1, D7 and playtime are green, then 15–16/day for 7+ days.
- If test stats are bad, check demographics before changing the game.
- A $50–100 test shows whether core gameplay holds attention before building long-term retention features.
- Reviving a dead game with about 20 credits over 2 days brings enough players to re-measure stats.
- Loop: run about a week, improve every non-green stat, repeat. Niche games can alternate 5 days of ads with a week of fixes.
- Beta mode is disputed:
    - Some run 3 days of ads in beta, fix red stats, then run real ads; beta data reportedly doesn't feed recommendation stats.
    - The owner says not to use beta mode for ads; use playtesters instead (owner-recommended).
    - Beta gets no home-recommendation exposure, so a beta can't break out on its own.
- Multiplayer and round-based games need 20–32 credits/day so lobbies aren't empty. Empty lobbies kill stats.
- PvP duel games may need far more, around $100/day, unless they have bots (owner).
- At 32/day, about 3 days may be enough for home recommendations if CTR holds.
- Test with about 5 credits to see whether players wait for a round. Add bots to fill matches, and remove them later.
- Multiplayer games should hold somewhat more than 50 home-recommendation CCU before stopping ads (low confidence).
- Saturated genres like +1 Speed need 15–16/day. Solo-playable games do fine at 12/day for 7–14 days.
