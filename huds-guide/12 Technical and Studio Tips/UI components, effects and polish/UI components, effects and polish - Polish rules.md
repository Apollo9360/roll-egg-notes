# UI components, effects and polish - Polish rules

Up: [[UI components, effects and polish]] · Previous: [[UI components, effects and polish - Effects recipes]] · Next: [[Declarative UI and tooling]]

- Tween UI, and pair a darker outer UIStroke with a lighter inner stroke (e.g. fully black outer, white inner).
- Panel style that reads well: a header frame over a black background at 0.5–0.7 transparency.
- Dividers: a thin frame with UIGradient transparency 0 to 1.
- Use consistent UICorner, stroke sizes and text sizes, and at most 1–2 fonts.
- Use 2x2 or 3x2 button grids rather than 3x1 stacks, and keep icons 1:1.
- Enlarge the icon and price in upgrade tooltips, and keep big numbers readable.
- Don't write "Robux" under the Robux icon.
- Put rarely used side buttons in a hamburger submenu.
- Show the pointer cursor only on buttons, to avoid accidental purchases.
- Use gradients only on important elements; no drop shadow on the X button.
- Outline icons, and don't color them the same as the background.
- Don't mix AI-generated UI with hand-styled UI. AI-made UI is easy to spot, and players call it out.
- UI packs are widely considered worth buying.
