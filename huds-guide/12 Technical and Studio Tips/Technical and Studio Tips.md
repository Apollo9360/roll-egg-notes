# Technical & Studio Tips

Up: [[Hud's Guide To Roblox Success]]

Most technical problems trace to three fixes: Scale-based user interface (UI), ProfileStore for player data, and profiling against a 16.66 ms frame budget. Hand-rolled DataStores tend to lose data past ~100 concurrent users (CCU); never trust the client, use a soft-shutdown script for updates, and never privatize a live game to fix a bug.
