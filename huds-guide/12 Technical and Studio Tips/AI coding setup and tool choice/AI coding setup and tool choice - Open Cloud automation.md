# AI coding setup and tool choice - Open Cloud automation

Up: [[AI coding setup and tool choice]] · Previous: [[Which tool (community view over time)]] · Next: [[Bulk-creating gamepasses and developer products]]

- Open Cloud lets an agent upload images and create or price gamepasses and developer products.
- A 403 on asset upload means the key lacks asset write permission or belongs to the wrong account.
- Claude in a browser can also fill product forms; one developer made 79 developer products in about 5 minutes.
