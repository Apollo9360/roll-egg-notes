# Which tool (community view over time)

Up: [[AI coding setup and tool choice]] · Previous: [[Toolchain for agent coding]] · Next: [[AI coding setup and tool choice - Open Cloud automation]]

| Period | Prevailing view | Confidence |
|---|---|---|
| Early July 2026 | Opus 4.8 much better than Sonnet 4.6; Codex claimed better for Roblox (disputed); Gemini poor for code | Medium |
| Late July 2026 | Opus has better taste and cleaner code; GPT 5.6 better at logic bugs; $20 Codex best value | Medium |
| Early August 2026 | Codex usage lasts ~3–5x longer than Claude Pro at similar price; Opus 5 for planning | Medium |
| Late August 2026 | Codex and Claude Code most used; Claude slower but higher quality, Codex faster with more usage | High |
| Early September 2026 | Sol 5.6 better and cheaper than Fable; Luna cheap for Studio tasks; Sonnet 5 adequate | Low |
| Mid-September 2026 | Claude Code finished long task lists where Codex stalled on playtesting; heavy users burned a $100 plan in 2 days | Medium |
| Late September 2026 | Opus 5.5 called strongest; list price ~$4/$20 per million tokens versus ~$10/$50 for GPT 6 Astra; $100 Claude plan advised for heavy use | High |
| October 2026 | Opus 5.5 dominant, seen beating Codex for scripting, UI, VFX and cutscenes; Sonnet 5.5 cheaper and good at UI; Codex better at UI icons and planning | Medium |

- Codex-family routing: Luna for small fixes, Terra for multi-system bugs, Sol for complex long-running bugs.
- Claude limits are a 5-hour window plus a weekly cap; Max plans cost $100 (5x) and $200 (20x). Opus 5.5 VFX work can exhaust a 5-hour window.
- Use at least "high" effort ([effort docs](https://platform.claude.com/docs/en/build-with-claude/effort)).
- Heavy MCP servers burn usage fast.
- Free or cheap credits: GitHub Copilot is free for students, students can get ~$100 of Codex credits, and Google Cloud offers $300 of trial credits.
