# UI scaling and layout - UIStroke

Up: [[UI scaling and layout]] · Previous: [[UI scaling and layout - Conversion plugins]] · Next: [[UI scaling and layout - Layout fixes]]

- UIStroke doesn't scale with screen size by default.
- Set stroke sizing to scaled (~0.07), or script strokes relative to 1920x1080.
- Enable scaled stroke and miter for mobile. Use bevel to avoid holes in round letters.
- Text overlapping on mobile usually means UIStroke isn't scaled.
